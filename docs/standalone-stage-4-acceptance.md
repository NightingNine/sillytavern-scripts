# A.U.T.O 独立版阶段 4 验收记录

## 结论

阶段 4 已完成本地实现与验收。独立版现已具备正式产物、自建产物、版本历史、上下文范围开关、全局附属世界书资料库和项目级激活规则；脚本版仍保持冻结，未被本阶段修改。

本阶段只迁移“产物与创作资源”，不提前实现最终角色卡发布、AI 世界书重组或 ZIP 交付；这些属于阶段 5。

## 数据与行为证据

- AI 完整回复保存后再按当前步骤协议提取产物；流式草稿不直接写入正式产物库，取消时仅从已正式保存的回复提取。
- Step 5 的原点、画像和状态分别保存；同一身份生成新内容会追加版本，相同内容只重新选中已有版本。
- 产物保存于项目独立的 `artifacts.json`，编辑、删除、清空、重试或切换对话都不会连带修改产物历史。
- 任意 AI 历史回复可再次执行“加入产物”；不符合当前步骤交付协议时明确提示，不制造空产物。
- 自建产物必须指定步骤、名称与正文，与 AI 产物共用版本、搜索、上下文和后续发布语义。
- 默认只装配当前步骤及之前的已启用产物；开启“包含后序”后才追加已存在的后续步骤产物。
- 自动上下文会避免重复发送当前对话已完整包含的同一产物；用户可明确强制开启或关闭单项产物。
- 附属世界书保存在全局资料库，每个项目分别控制整本和条目；重新导入同名源文件会同步原快照并保留书本身份。
- 常驻条目每轮激活；关键词条目只匹配本轮用户输入，并兼容主/次关键词、大小写、整词和正反组合逻辑。
- 命中的附属资料进入独立的低优先级提示词区块，不进入正式产物接口，也不作为阶段 5 的发布材料。
- 导入内容仅作为不可信文本解析，不执行 JSON 中的脚本、EJS、扩展代码或表达式；单文件上限为 10 MB。

## 自动验证

`dotnet run --project standalone/AutoCardStudio.Host/AutoCardStudio.Host.csproj -c Release -- --self-test` 覆盖并通过：

- Step 5 三产物提取、版本追加、内容去重与重开恢复。
- 自建产物保存、当前会话重复抑制、单项强制开启及后序范围开关。
- 世界书 JSON 导入、同源同步、项目开关、常驻命中、主/次关键词正反命中与关闭条目排除。
- 正式产物和附属参考资料分区装配，提示词预览与实际生成共用同一装配器。
- 阶段 1—3 的存储、协议、多对话与消息操作回归自检继续通过。

前端同时通过 `node --check` 和浏览器界面检查。浏览器确认自建产物保存后立即进入产物列表并显示版本；附属世界书隐藏文件控件无法由当前自动化驱动接管，因此上传控件本身以静态检查和后端导入自测为验收证据，不把自动化工具限制包装成应用缺陷。

## 存储、恢复与回退

- `artifacts.json`、全局 `resources/reference-worldbooks/library.json` 和项目 `reference-worldbooks.json` 均使用原子替换与上一份有效文件恢复机制。
- 世界书导入原件按 SHA-256 归档；转换失败不会覆盖已有资料。
- 所有变更只位于独立版分支与独立工作树。需要回退时可回到阶段 3 提交，脚本版无需任何处理。
