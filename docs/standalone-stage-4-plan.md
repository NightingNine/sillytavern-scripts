# 独立版阶段 4 迁移计划：产物与创作资源

## 任务封套

- **目标**：完整迁移脚本版的正式产物库、自建产物、版本选择、上下文开关、后序产物与附属世界书闭环。
- **成功条件**：AI 回复完成后只提取当前步骤允许的正式产物；产物与对话独立保存；每个身份保留全部版本且只发送当前选中版本；自建产物能参加后续上下文；附属世界书全局共用、项目独立启用，并只按常驻或本轮关键词命中发送。
- **范围**：`artifacts.json`、全局附属世界书资源、项目级启用状态、产物/世界书管理界面、提示词预览与实际生成的统一装配、Token 预算。
- **禁止动作**：不修改脚本版；不实现最终角色卡发布与世界书重组；不把附属世界书写入正式产物；不执行导入 JSON 中的脚本、EJS、扩展代码或未知表达式。
- **迁移边界**：继续只支持固定 A.U.T.O v2.0 工作流；其他预设的通用工作台方案仍留到脚本版功能完全迁移以后。

## 已确认规则

1. 对话编辑、删除、清空、重试和切换不修改已经入库的产物。
2. 同一“步骤 + 产物身份”的新内容形成新版本；相同内容只切换到已有版本，不重复新增。
3. 默认只发送当前步骤及之前已开启的产物；用户开启“后序”后才发送之后步骤的产物。
4. 当前会话已经包含所选产物时，自动模式避免重复发送；用户仍可明确强制开启或关闭。
5. 自建产物必须指定步骤、名称和正文，与 AI 产物使用同一版本、上下文与后续发布语义。
6. 附属世界书保存在所有项目共用的本地资料库；每个项目独立控制整本及条目是否启用。
7. 常驻条目每轮发送；关键词条目只扫描本轮用户输入，支持 SillyTavern 常见主关键词、次关键词逻辑、大小写和整词字段。
8. 附属世界书只作为低优先级参考资料，不进入产物库、重组输入或最终角色卡。

## 验收矩阵

- 正向：29 步正式标签、Step 5 角色三类产物、Step 18 schema、Step 23 状态栏围栏和自建产物均可入库。
- 版本：新版本、相同内容去重、版本切换、最新版编辑、身份删除均能持久化。
- 解耦：形成产物后删除/编辑/重试原消息，产物版本历史保持不变。
- 上下文：前序、当前、后序开关、单项自动/开启/关闭与提示词预览一致。
- 世界书：常驻正命中；无关键词不命中；主/次关键词逻辑正反命中；关闭整本或条目后不发送。
- 安全：超限导入、无正文 JSON 和损坏 JSON 被拒；未知字段只保留为静态数据，不执行。
- 隔离：提示词中能看到实际命中的附属资料，但正式产物接口中永远没有附属世界书条目。
