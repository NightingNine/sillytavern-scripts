# 独立版迁移阶段 6 计划：数据安全与最终对等

## 本轮范围

- 只修改独立版分支，脚本版继续冻结。
- 先补齐项目导入导出、工作区备份、恢复预检、诊断与安全清理，确保脱离 SillyTavern 后用户仍能自助维护数据。
- 再补齐新手引导、资源管理、桌面侧栏拉伸与最终移动端细节。

## 数据安全合同

- 项目导出必须包含 29 个步骤、全部对话、产物版本和该项目的附属世界书启用状态；不包含 API 密钥。
- 项目导入永不覆盖现有项目；始终分配新 ID、生成不冲突名称，并在完整校验后一次性写入。
- 工作区备份使用 ZIP，包含清单和 SHA-256；备份目录本身不得递归进入备份。
- 恢复前必须先做只读预检；正式恢复前自动制作恢复点。校验失败时不得改动当前数据。
- 全量清理只处理独立版明确拥有的 `data` 内容和 Windows 凭据项，必须二次确认；不触碰脚本版、SillyTavern 或其他目录。
- 诊断不得输出 API 密钥、提示词正文、对话正文或产物正文。

## 最少实现结构

- 使用一个 `WorkspaceMaintenanceService` 集中处理传输、备份、恢复、诊断与清理，避免为每个动作增加一层服务。
- 继续复用 `AtomicJsonFile` 与现有数据模型，不增加数据库和第三方依赖。
- `Program.cs` 只注册服务和薄 API；前端以一个居中维护窗口承载操作。

## 验收

1. 项目导出后导入为新项目，原项目保持不变，步骤/对话/产物/参考书选择一致。
2. 备份清单哈希可验证；篡改包或路径穿越包被拒绝。
3. 恢复预检不写盘，恢复失败能回滚，成功后所有存储可重新初始化。
4. 诊断只返回元数据与错误位置，不泄露正文或凭据。
5. Release 仍为单个自包含 `A.U.T.O.exe`，数据默认位于 EXE 同级 `data`。
