# A.U.T.O 独立版阶段 1 验收记录

## 验收结论

阶段 1 已于 2026-08-04 通过。当前独立版形成了不依赖 SillyTavern 的最小可运行闭环：单文件启动、自动浏览器入口、三栏工作台、九组 29 步、多项目、安全保存、关闭与重开恢复。

这不是完整独立版发布稿。模型、预设、对话、产物、附属世界书和最终交付仍按后续阶段迁移。

## 已验证行为

| 范围 | 验收结果 |
|---|---|
| 项目存储自检 | 创建、更新、重开和 revision 冲突均通过 |
| 浏览器工作台 | 三栏布局、29 步、设置页、项目编辑与步骤切换正常 |
| 连续编辑 | 项目名称与创作母题快速连续修改不会互相覆盖 |
| 重开恢复 | 项目名称、创作母题和当前步骤在服务重启后完整恢复 |
| 页面错误 | 浏览器控制台无 error 或 warning |
| 单实例 | 第二次启动正常退出，首实例继续运行且持有唯一写入权 |
| 本地会话 | 未持有会话 Cookie 的 API 请求被拒绝；启动令牌只用于换取本地会话 |
| 便携发布 | Release 目录只包含一个自包含 `A.U.T.O.exe` |
| 发布包运行 | 单文件程序可独立启动，内置 HTML/CSS/JS 与健康接口均返回 200 |
| 安全关闭 | 关闭后进程退出，临时实例记录被移除 |

## 数据与回退

- 默认资料目录为程序同级 `data`；开发验收全部使用临时目录，没有接触脚本版或正式资料。
- 项目写入采用临时文件、读回校验和安全替换；旧有效文件保留为 `.previous`。
- 删除项目时移动到 `data/trash/projects`，不立即永久删除。
- 每次更新携带 revision；旧页面不能静默覆盖更新后的项目。
