# A.U.T.O 独立版阶段 2 验收记录

## 当前结论

阶段 2 的功能实现与本地协议验收已经完成：独立版可以导入 A.U.T.O 预设和正则、保存全局模型连接、在步骤中即时显示用户消息、接收流式或非流式回复、停止请求，并在重开后恢复对话。

阶段门尚差一次用户真实模型连接复核。当前测试使用本地协议替身覆盖请求与响应格式，没有读取或复用用户现有的 API 密钥，因此不能把它记为真实外部模型验收。

## 已验证行为

| 范围 | 验收结果 |
|---|---|
| A.U.T.O 预设 | 只采用最长 `prompt_order` 实际引用的 29 步与重组条目；缺项会拒绝替换 |
| 正则资源 | 预设内置正则与独立正则均可解析；显示和后续 Prompt 使用同一套启用规则 |
| 原始来源 | 导入原件、文件名与 SHA-256 保存在 `data/imports`，可追溯且不改写原件 |
| Windows 凭据 | 密钥可保存、读取和删除；测试数据目录全文检查未出现密钥明文 |
| 模型协议 | OpenAI 兼容、Anthropic Claude、Google Gemini 的非流式响应自检通过；OpenAI SSE 流式增量通过 |
| 即时消息 | 点击生成后，用户消息在 AI 完成前立即出现在当前步骤 |
| 流式生成 | 增量正文正常显示，完成后保存用户与 AI 两条消息 |
| 非流式生成 | 完整回复正常显示并保存 |
| 重开恢复 | 浏览器重新载入后，流式和非流式对话仍存在且顺序不变 |
| 停止 | 取消令牌可中断网络请求；生成协调器收到停止后发出 `cancelled`，不会误记为完成 |
| Revision | 生成固定项目、步骤和 step revision；旧页面不能把回复写进已变化的步骤 |
| 构建 | Debug 构建 0 警告、0 错误；前端 JavaScript 语法检查通过 |
| 单文件发布 | Release 生成单个自包含 `A.U.T.O.exe`，发布程序内置自检通过 |

## 本阶段边界

- 当前每个步骤只有一个默认对话；命名、多对话切换、编辑、删除和重试在阶段 3 实现。
- 当前只发送项目母题、当前步骤预设和当前步骤会话；正式产物与附属世界书上下文在阶段 4 实现。
- 当前不提取产物，也不生成角色卡发布包。
- Token 使用保守估算；精确 tokenizer 属于后续兼容工作。

## 真实模型复核清单

用户在独立版设置中新增自己的连接后，只需完成以下一次复核：

1. 获取或手动填写一个真实模型 ID。
2. 在 Step 1 写入创作母题并发送一条短消息。
3. 确认用户消息立即出现，AI 回复可流式完成，刷新后仍存在。
4. 再生成一次并点击“停止”，确认停止后不会继续追加内容。

真实模型通过后，阶段 2 状态可从“已实现，待真实模型复核”更新为“已验证”，随后进入阶段 3。
