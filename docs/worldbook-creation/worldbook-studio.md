# 世界书创作台

世界书创作台是一款全屏世界书管理脚本，界面风格参考 A.U.T.O 角色卡创作台。它不会调用 AI，适合集中整理、检查和迁移世界书条目。

## 安装

1. 确认 SillyTavern 已安装并启用酒馆助手 4.9.1 或更高版本。
2. 在酒馆助手中新建脚本。
3. 粘贴下面这一行并启用脚本：

```javascript
import 'https://cdn.jsdelivr.net/gh/NightingNine/sillytavern-scripts@worldbook-studio-v0.1.0/dist/worldbook-creation/worldbook-studio/index.js';
```

4. 在 SillyTavern 的扩展菜单中点击“世界书创作台”。

如果以前安装过同名扩展版，脚本会接管同名菜单入口，避免显示两个入口。确认脚本工作正常后，可以停用或删除旧扩展。

## 已有功能

- 记住上次打开的世界书，并在选择器中定位当前世界书。
- 新建、删除、重命名、导入与导出世界书。
- 新建、复制、删除和批量启用或停用条目。
- 在不同世界书之间复制或移动条目。
- 检查空内容、无触发条件、重复关键词、包含关系和标题重复等问题。
- 编辑关键词、插入位置、消息角色、概率、扫描深度、递归与分组设置。
- 左右栏支持鼠标拖动和键盘方向键调整宽度。

## 数据与重命名说明

脚本通过酒馆助手公开接口读写世界书，并在保存时保留界面没有展示的原始字段。

酒馆助手目前没有原生“重命名世界书”接口，因此创作台会创建同内容的新世界书、同步全局以及当前角色卡和当前聊天的绑定，再删除旧世界书。其他未打开角色卡中指向旧名称的绑定不会被自动修改，需要之后手动调整。

## 使用建议

- 跨世界书移动、删除世界书和重命名都属于会立即影响酒馆数据的操作，请先做好备份。
- 冲突检查只给出提示，不会自动改写条目。
- 若界面没有出现，请先确认酒馆助手脚本已启用，然后刷新 SillyTavern 页面。
