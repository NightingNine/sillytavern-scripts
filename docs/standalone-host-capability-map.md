# A.U.T.O 独立版 Host 能力与缺口表

## 基本信息

- 目标应用：A.U.T.O 角色卡创作台独立版第一阶段。
- 候选 Host：Windows 自包含本地服务 + 默认浏览器。
- 目标平台：Windows x64；最终用户无需安装 Node.js、.NET Runtime 或 SillyTavern。
- 证据日期与环境：2026-08-04；开发机具备 .NET SDK 10.0.202、ASP.NET Core 10.0.6、Node.js 24.13.1。

## 能力清单

| 能力 | 必需/可选 | 谁消费 | 当前设计 | 缺失时处理 | 所属边界 |
|---|---|---|---|---|---|
| 本地耐久存储 | 必需 | 项目、产物、资源、设置 | 程序旁 `data` 目录，JSON 分文件保存 | 停止写入并提示选择可写目录 | Storage |
| 安全写入与版本冲突 | 必需 | 项目与资源保存 | 临时文件写入、校验、原子替换、revision 检查 | 保留旧文件，不重调模型 | Storage |
| 模型网络请求 | 必需 | AI 生成与世界书重组 | 本地服务代理 OpenAI 兼容、Claude、Gemini | 明确错误，不修改正式数据 | Model Gateway |
| 流式与取消 | 必需 | 对话界面 | 本地服务标准化事件流，取消贯穿到供应商请求 | 保留已显示草稿但不提取产物 | Model Gateway |
| 密钥保存 | 必需 | 模型连接 | Windows 凭据管理器 | 仅允许当次临时使用并明确提示 | Secret |
| 文件导入导出 | 必需 | 项目、预设、正则、世界书、角色卡 | 浏览器上传到本地服务；下载 JSON/PNG/ZIP/Markdown | 不静默改写未知字段 | File |
| 后台任务 | 必需 | 自动保存、备份、更新 | 单实例本地服务队列 | 失败可重试且不阻塞查看已有资料 | Task |
| HTML 预览沙箱 | 必需 | 对话代码块 | `iframe sandbox`，只渲染 HTML/CSS，不执行脚本 | 显示源码 | Preview |
| 更新与诊断 | 必需 | 应用维护 | 版本清单、校验下载、旧版回退、脱敏日志 | 继续运行当前版本 | Update/Diagnostics |

## Host 选择

| 候选 | 满足能力 | 成本与风险 | 结论 |
|---|---|---|---|
| 纯单文件 HTML | 界面与部分导入导出 | 无法可靠保管密钥、绕过浏览器跨域限制或管理 `data` 文件 | 排除 |
| Node.js 本地服务打包 | 与现有 JavaScript 接近 | Windows 凭据管理和稳定单文件发布需要额外原生包装 | 不采用首选 |
| .NET 10 自包含本地服务 | 单文件发布、HTTP、文件、凭据管理、ZIP 与更新均可原生实现 | 发布包较大；需要维护少量 C# 宿主代码 | 采用 |
| Tauri/WebView 桌面壳 | 文件和密钥能力完整 | 不符合“默认浏览器打开”的既定入口，新增 Rust/WebView 维护 | 排除 |

## 当前选择

- 宿主：`.NET 10 ASP.NET Core Minimal API`，发布为 Windows x64 自包含单文件程序。
- 前端：原生 HTML/CSS/JavaScript ES Modules，迁移现有界面和确定性业务逻辑，不引入 React/Vue。
- 选择依据：符合便携式 `.exe`、默认浏览器、Windows 凭据管理器、`data` 文件夹和最少依赖要求。
- 重新评估条件：未来需要 macOS/Linux、多人远程访问、云同步或插件运行时。

## 平台边界

| 领域 | 允许依赖 | 禁止直接依赖 | 目标位置 |
|---|---|---|---|
| 前端 UI | 本地 HTTP API、事件流 | 文件系统、Windows 凭据、SillyTavern 全局对象 | `src/web` |
| 项目与资源 | Storage API | 浏览器 IndexedDB 作为正式事实源 | 本地服务 |
| 模型调用 | Model Gateway API | 浏览器保存或直传长期密钥 | 本地服务 |
| A.U.T.O 规则 | 版本化预设、正则、项目快照 | SillyTavern 当前聊天/预设/正则 | 前端纯模块 |
| 发布 | Packaging API | 直接写入 SillyTavern 数据目录 | 本地服务 |

## 当前证据与缺口

- 已验证：开发机具备所选 SDK；目标能力均有 Windows/.NET 原生实现路径；脚本功能基线和宿主依赖已盘点。
- 未验证：自包含发布体积、三类真实模型流式差异、PNG 角色卡在目标 SillyTavern 版本中的导入回放、自动更新替换运行中程序。
- 阻塞缺口：无设计级阻塞；上述项目必须在对应实施阶段验证，失败时不得声称功能对等。
