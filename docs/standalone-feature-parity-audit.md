# A.U.T.O 独立版功能对等审计

## 1. 审计目标

- 第一阶段只迁移当前脚本版已经存在的能力，不先扩展其他预设或新的创作模式。
- 独立版不得依赖 SillyTavern 页面、酒馆助手插件或其浏览器全局对象运行。
- “功能对等”按用户取得的结果、数据规则、异常行为和恢复能力判断，不以复制原技术调用为判断标准。
- 本文是完整设计与后续验收的功能基线；未列入且未经确认的能力不能被当成已经迁移完成。

## 3. 对等判定规则

每项能力依次经过以下状态：

1. `已识别`：已从代码、说明或真实运行找到基线行为。
2. `已映射`：已确定独立宿主中的等价入口、数据 owner 和失败方式。
3. `已实现`：独立版能够执行该流程。
4. `已验证`：在目标浏览器和便携启动程序中完成相关行为、保存重开和异常测试。

第一阶段只有全部必需项达到 `已验证`，才能称为“脚本版完整移植”。

## 6. 当前结论与未决项

- 独立版完全脱离 SillyTavern 运行。
